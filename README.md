# 교육과정 시수 플래너

충남여자고등학교 2027~2029학년도 예상 시수 · 2026.10.28 여러 교과 이어서 인쇄판 · 2026.10.29 반 수 시뮬레이션 추가

## 반 수 시뮬레이션 (2026.10.29 추가)

A4 인쇄본과 같은 표(담당 교과 · 구분 · 과목명 · 학년별 반당 시수·담당 반 수·교과 시수 · 교사 수 · 자체/배정/총시수 · 교사 1인 평균)에 **반당 인원**(선택과목은 괄호 안에 과목 전체 선택 인원)을 더해, 반 수를 바꾸면 바로 다시 계산해 보여 줍니다.

1. **반 수 시뮬레이션** 메뉴에서 학년도와 학기를 고릅니다.
2. **선택군**을 고르면 목표 반 수(기본: 학급 수 × 택N, 예: 13학급 × 택3 = 39반)가 나옵니다. −를 누르면 반을 줄여도 반당 인원이 가장 적게 늘어나는 과목부터 1반씩 줄이고, ＋를 누르면 반당 인원이 가장 많은 과목에 1반을 더합니다. 목표 반 수를 직접 입력해도 됩니다.
3. 표의 **담당 반 수**(−/＋ 또는 숫자 입력)로 시수가 많은 과목을 직접 줄일 수도 있습니다. 공통·융합 과목은 그 교과가 맡은 반만 줄어듭니다. 학교 지정 과목은 학급 수로 정해지므로 바꿀 수 없습니다.
4. 바뀐 칸은 노란색으로 표시되고 ‘기존’ 값이 아래에 나옵니다. 반당 인원, 교과 시수, 교과 총시수, 교사 1인 평균, 학기 합계가 함께 바뀝니다.
5. **예상안에 적용**을 눌러야 저장됩니다. 적용 전에는 예상안이 바뀌지 않고, ‘기존값으로’를 누르면 시뮬레이션을 처음으로 되돌립니다. 적용 후에는 선택군 목표가 새 합계로 저장되어 선택군 조율·3개년 비교·A4 인쇄에 함께 반영되며, ‘되돌리기’로 복구할 수 있습니다.

반당 인원 = 예상 신청 인원 ÷ 반 수입니다(학교 지정 과목은 학생 수 ÷ 학급 수). 신청 인원은 선택자료를 쓰고, 없으면 참고 추정·과거 선택 환산·보충 수요를 씁니다. 화면 위의 학년별 학생 수(또는 ‘계산 기준·자료’의 입학 연도별 학생 수)를 입력하면 ‘학생 수 × 택N’에 맞춰 환산합니다. 2025·2026 입학생은 2027학년도 반편성 기준 학생 수인 243명·274명이 들어 있습니다. 2027학년도 2·3학년 선택과목은 과목별 선택인원(2026.10.28.) 최종 인원을 그대로 쓰며, 선택군 합계가 이 학생 수 × 택N과 같습니다. 2027학년도 이후 입학생은 정원이 정해지면 입력합니다.

## 웹에서 수정한 값으로 PDF 저장

1. **A4 인쇄 · PDF** 메뉴를 누릅니다.
2. 학년도·학기·시수 표시 방식을 고르고, **인쇄할 교과 선택**에서 필요한 교과를 체크합니다. 국어·수학·영어·체육·음악·미술·정보·일본어·중국어·한문과 사회·과학의 세부 교과를 함께 선택할 수 있습니다.
3. **인쇄 배치 → 여러 교과 이어서 인쇄**가 기본값입니다. 같은 학년도·학기의 선택 교과를 한 표에 모아 비교하고, 한 장에 들어가지 않는 분량만 다음 장으로 이어집니다. 교과마다 장을 나누려면 **교과별 새 페이지**를 선택하세요. 이때 사회·과학의 세부 교과도 각각 인쇄하려면 **사회·과학은 각각 묶어서 출력**을 해제합니다. 교과 선택·인쇄 배치·묶기 설정은 이 브라우저에 저장됩니다. 표의 담당 반 수를 눌러 수정하고 적용하면 시수·교사 평균이 즉시 갱신됩니다.
4. **현재 값으로 인쇄 / PDF 저장**을 누릅니다.
5. 인쇄 창에서 **PDF로 저장, A4, 가로, 배율 100%, 머리글·바닥글 끄기**를 선택합니다.

학년도·학기가 바뀌면 새 페이지를 시작합니다. 이어서 인쇄할 때 각 교과의 수치는 오른쪽에, 선택 교과 전체 합계는 표 아래에 표시합니다. 공통·융합·교양 과목은 배정받은 담당 교과에 포함됩니다. 담당 교과별로 과목을 묶고 1·2·3학년의 반당 시수·담당 반 수·교과 시수를 나란히 표시합니다. 구분은 공통·일반·진로·융합이며, 교과별 교사 수·시수·평균은 오른쪽에 표시합니다. 담당 반 수 × 반당 시수 = 교과 시수입니다. 글자는 11pt 검정이며 긴 표는 다음 쪽으로 나눕니다. 미정·미배정이 남은 평균은 *로 표시하고 초과 배정은 보류합니다. 인쇄 기능은 편성이나 배정을 자동 수정하지 않습니다.

**반 단위 배정 PDF (2026.10.21 고정본)**은 웹에 저장된 조율안의 소수 담당 반 수가 있는 20개 과목을 정리한 자료입니다. 과목별 총 반 수·배정 총시수는 보존하고, 나뉜 반을 기존 담당 교과 중 해당 학기 평균이 낮은 곳에 배정했습니다. 미배정 교양 과목은 그대로입니다. 최신 조율안의 2028년 2학기 과학의 역사와 문화는 6반·18시간으로 배정되었습니다. 이후 편집값은 위 ‘현재 값으로 인쇄 / PDF 저장’으로 출력하세요.

## 새로 추가한 선택군 조율

1. **선택군 조율** 메뉴에서 학년도와 학기를 고릅니다.
2. 2·3학년을 함께 보거나 한 학년만 선택합니다. 선택군마다 택 수, 학급 수, 목표·현재 반 수가 표시됩니다.
3. 표에서 과목별 예상 반 수를 입력하거나 ＋·−를 누릅니다. 같은 선택군의 다른 과목을 현재 반 수 비율로 함께 배분한 제안이 열립니다.
4. **선택군 함께 적용**으로 저장합니다. 직접 입력한 과목의 반 수를 유지하고, 전체는 학급 수 × 택 수에 맞춥니다. 0반 과목을 열려면 해당 과목에 직접 반 수를 입력합니다.
5. 과거 인원 숫자를 누르면 원본 신청인원·개설반·이수 학기·출처와 보충 수요를 볼 수 있습니다. 신청인원은 과거 자료이며 미래 확정 인원이 아닙니다.
6. 반 수를 조율한 뒤 **사회·과학 재배정 검토**를 누르면 관련 교과 안에서 반 단위로 시수를 나눈 제안을 보고 적용할 수 있습니다.

반 수 변경은 해당 학년도·학년·학기의 같은 선택군에만 반영합니다. 미개설·0반인 다른 과목은 자동으로 열지 않습니다. 미정이 남으면 합계 맞추기를 보류합니다. 부족·초과 또는 미정 상태를 표에 표시합니다.

## 보정안과 영어 이동안

**보정안 비교·불러오기**에서 2029학년도 1학기 세계 문화와 영어의 택1 → 택4 이동 전후를 비교합니다. 기존 택1과 택4 선택군 모두 재배분한 결과와 공통·융합 배정 후 교사 평균을 표시합니다.

비교 창은 최신 기준 가정 두 안의 비교입니다. 현재 직접 편집한 반 수를 두 안에 자동 대입하지 않습니다. 현재 교사 수·학급 수는 적용하며, 해당 수가 기준값과 다르면 관련 교과 배정도 다시 계산합니다.

**기존 교육과정 보정안 불러오기** 또는 **영어 이동안 불러오기**를 누르면 3개년 과목·메모·배정을 해당 안으로 교체합니다. 현재 교사 수·학급 수·수업 주 수는 보존합니다. 개인 추가 과목은 교체되므로 필요하면 먼저 예상안을 저장하세요. 적용 직후 되돌릴 수 있습니다.

처음 여는 브라우저의 기본안은 2026.10.21 웹 조율안의 소수 담당 반 수를 정수로 정리한 안입니다. 기존 브라우저의 개인 저장안은 자동 교체하지 않습니다. 아래 경제·윤리 보정 설명은 비교 창에서 제공하는 참고 가정에 관한 내용이며, 사용자 조율안에 자동 대입하지 않습니다.

## 계산 기준

- 2025·2026 입학생 13학급, 2027 입학생부터 12학급. 2028·2029 입학생은 2027 입학생 교육과정을 적용합니다.
- 2027학년도 2·3학년 선택과목은 과목별 선택인원(2026.10.28.)의 최종 인원·개설반을 씁니다(choice-final.js). 2026 입학생 274명, 2025 입학생 243명과 합계가 같습니다. 이미 저장된 예상안은 처음 열 때 인원을 최종값으로 바꾸고, 직접 수정하지 않은 과목의 반 수만 최종 개설반으로 맞춥니다. 2026.9.28. 자료는 2028·2029학년도 추정과 원자료 조회에 그대로 씁니다.
- 2028·2029학년도는 기존 과목의 예상 반 수 비율로 배분하고, 선택자료 없는 과목은 같은 선택군의 기존 반 수 평균을 가중치로 사용합니다. 소수 부분이 큰 순서로 남는 반을 나누어 목표 합계를 맞춥니다.
- 경제 57명, 윤리와 사상 99명은 사용자가 알려 준 2026학년도 2학년 2학기 택3 선택군의 신청인원입니다. 239명 × 택3 = 717건 중 비율로 각각 7.95%, 13.81%를 사용합니다.
- 경제 보정은 2028·2029학년도 3학년 1학기 택4, 윤리와 사상 보정은 같은 두 학년도 2학년 2학기 택3에 적용합니다. 원본의 0명·0반과 180명 등은 수정하지 않고 조회 자료에 보존합니다.
- 교과 총시수 = 반당 주당시수 × 개설 반 수. 교사 평균 = 자체 시수 + 배정받은 시수의 합 ÷ 해당 학기 교사 수. 창체 제외, 교사 수 미정·0명은 미산정입니다.
- 참고 보정안의 학기별 학교 총시수: 2027년 1,102 / 1,102, 2028년 1,073 / 1,073, 2029년 1,044 / 1,044시간. 사용자 조율안의 현재 합계는 화면에서 확인합니다.
- 학급 수를 바꾸면 미래의 아직 조율하지 않은 선택군 전체를 다시 배분합니다. 직접 조율한 과목이 있는 선택군과 실제 선택자료 반 수는 보존하므로 합계 점검이 필요할 수 있습니다.

## 공통·융합·교양 배정

최신 보정안의 관련 교과 기준은 사용자 제공 사회·도덕·과학 교육과정 PDF의 내용에 따른 편성 가정입니다.

- 여행지리, 기후변화와 지속가능한 세계 → 지리
- 금융과 경제생활, 사회문제 탐구 → 일반사회
- 역사로 탐구하는 현대 세계 → 역사
- 윤리문제 탐구 → 윤리
- 기후변화와 환경생태 → 생명과학·지구과학
- 과학의 역사와 문화, 융합과학 탐구 → 과학 4개 교과
- 통합사회 → 사회 4개 교과, 통합과학·과학탐구실험 → 과학 4개 교과

선택군 탭의 재배정은 위 범위에서 온전한 반 단위로 교사 평균의 균형을 고려합니다. 교사 수가 0·미정이거나 자체 시수가 미정인 교과는 자동 배정에서 제외합니다. 한 교과로 지정된 융합 과목은 그 교과에 배정합니다.

**공통·교양 시수 배정** 메뉴에서는 과목별 담당 반 수를 정수로 입력합니다. 배정 시수는 반당 시수 × 담당 반 수로 자동 계산합니다. 교양은 전체 담당 교과에 배정할 수 있습니다. 기존에 소수 반 수가 남은 안은 ‘소수 담당 반 수 정리’에서 미리 보고 일괄 적용할 수 있습니다. 온전히 배정된 반과 과목별 배정 총합은 유지하고, 나뉜 반만 모아 해당 학기 평균이 낮은 기존 담당 교과에 배정합니다. 교사 평균은 계산 결과이므로 소수 둘째 자리까지 표시합니다. 기존 배정 합계가 온전한 반 수가 아니거나 교사 수·시수가 미정인 경우, 보류된 배정은 자동 정리하지 않고 사유를 안내합니다. 과목의 전체 개설 반 수를 바꾸어 기존 배정이 초과하면 반영을 보류하고 재배정을 안내합니다.

## 기존 기능

2026.10.29부터 ‘과목별 예상 시수’와 ‘주당시수 배당표’ 메뉴는 없앴습니다. 반 수 조정과 교과별 시수 확인은 ‘반 수 시뮬레이션’, 과목별 반 수 조율은 ‘선택군 조율’, 인쇄는 ‘A4 인쇄 · PDF’에서 합니다.

- 교과별 평균 시수: 교사 수를 바꾸면 같은 교과의 두 학기와 이후 학년도에 반영합니다. 이전 학년도는 유지합니다.
- 3개년 비교: 현재 예상안의 교과별·과목별 총시수와 학기별 교사 평균을 확인합니다.
- 교육과정 원자료: 2025~2027 입학생 원본 편성을 확인합니다.

## 저장과 배포

수정 내용은 브라우저에 자동 저장되며 다른 사람과 자동 공유되지 않습니다. 예상안 저장으로 JSON을 보관하고 불러오기로 복구할 수 있습니다. 되돌리기는 현재 실행 중 최근 30회 변경을 지원하고 새로고침하면 기록이 사라집니다.

계산 기준·자료의 게시용 기본안 받기로 저장한 default-plan.js를 게시하면 새 방문자가 해당 안으로 시작합니다. 기존 개인 저장안이 우선합니다. 원자료 기준 전체 초기화는 최신 보정안과 별개이며, 보정안은 비교 창에서 불러옵니다.
