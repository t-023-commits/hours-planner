# 교육과정 시수 플래너

충남여자고등학교 2027~2029학년도 과목별 예상 시수를 살펴보고 수정하는 정적 웹사이트입니다.

## 바로 사용하기

`index.html`을 브라우저로 열면 실행됩니다. 인터넷 연결, 로그인, 별도 설치 없이 사용할 수 있습니다. 브라우저에 따라 로컬 파일의 자동 저장이 제한되면 **예상안 저장**으로 파일을 보관하세요.

- **교과별 평균 시수**: 첫 화면입니다. 학년도를 고른 뒤 교과별 1·2학기 교사 수를 각각 수정하면 해당 학기 교사 1인당 평균 시수가 계산됩니다. 교과명을 누르면 자체 과목과 배정받은 과목을 함께 확인합니다. 평균 시수 CSV와 인쇄도 가능합니다.
- **공통·교양 시수 배정**: 통합사회·통합과학·과학탐구실험·융합·교양 과목의 시수를 담당 교과에 나누어 배정합니다. 학년도·학기·과목 구분을 고른 뒤 ‘배정하기’를 누르면 배정 전후 평균을 비교하며 입력할 수 있습니다.
- **과목별 예상 시수**: 학년도·학기·학년·교과·선택군을 선택하고 개설 여부, 반당 주당시수, 반 수를 수정합니다. 선택군 필터에는 ‘2학년 1학기 · 선택군 B · 택3’처럼 표시되며, 고르면 해당 학년·학기로 이동합니다. 과목명을 누르면 집계 교과와 메모도 바꿀 수 있습니다.
- **3개년 비교**: 기본 화면은 교사 1인당 1·2학기 평균입니다. 교과별 또는 과목별 총시수 비교도 가능합니다.
- **주당시수 배당표**: 기본 ‘담당 교과별’ 보기에는 배정받은 시수를 반영합니다. ‘원래 과목별’ 보기에서는 기존 편성을 확인합니다. 각 보기의 CSV 내보내기와 인쇄/PDF 저장, 창체 포함 여부를 선택할 수 있습니다.
- **교육과정 원자료**: 2025~2027 입학생의 원본 편성표를 확인합니다.
- **계산 기준·자료**: 학급 수, 반당 인원 기준, 연간 환산 주 수와 출처를 확인합니다.

## 저장 및 공유

수정 사항은 현재 브라우저에 자동 저장됩니다. **예상안 저장 → 파일 내려받기**로 JSON 파일을 받은 후 다른 컴퓨터에서 **불러오기**를 누르면 이어서 쓸 수 있습니다. 저장된 파일을 불러오기 전에 이름과 과목 수를 확인합니다. 앱 내 미리보기에서 파일 다운로드가 제한될 때는 **내용 복사**를 사용하거나 일반 브라우저에서 사이트를 열어 저장하세요.

교사 수는 **학년도·교과·학기별로 별도 저장**됩니다. 배정 내역은 **학년도·학년·학기·과목별로 별도 저장**됩니다. 이전 예상안의 과목 편성과 교사 수는 유지하며 배정 항목만 추가합니다. 이전 버전에서 공통 과목 전체를 배정 가능한 교과로 옮겨 둔 경우 그 시수를 해당 교과의 전체 배정으로 이어받습니다.

GitHub에 게시해도 다른 사용자의 수정 내용이 자동으로 공유되지 않습니다. 공통 기본 예상안을 변경하려면 계산 기준·자료에서 **게시용 기본안 받기**를 누르고 받은 `default-plan.js`로 게시 폴더의 같은 파일을 교체하세요. 기존 개인 예상안이 저장된 브라우저에는 개인 예상안이 우선 적용됩니다.

**되돌리기**는 현재 실행 중 최근 30회 변경을 복구합니다. 새로고침하면 되돌리기 기록은 사라집니다. **전체 초기화**는 원자료 기준으로 돌아갑니다.

## GitHub Pages에 올리기

1. 이 폴더의 파일을 GitHub 저장소의 루트 또는 원하는 하위 폴더에 업로드합니다. `index.html`, `styles.css`, `data.js`, `model.js`, `assignments.js`, `app.js`, `default-plan.js`, `favicon.svg`를 함께 올려야 합니다. 새 배정 기능에 필요한 `assignments.js`도 반드시 포함하세요.
2. 새 저장소라면 GitHub의 **Settings → Pages**에서 브랜치를 이용한 게시를 선택하고 `main` 브랜치의 루트를 게시 위치로 설정합니다.
3. 기존 `curriculum` 저장소에 함께 올릴 때는 예를 들어 `planner` 폴더에 이 파일들을 넣으면 기존 사이트를 보존하면서 `/curriculum/planner/` 경로로 열 수 있습니다. 실제 주소는 저장소 게시 설정에 따릅니다.
4. 로컬에서 수정한 예상안도 게시하려면 `default-plan.js`를 함께 교체합니다.

이 폴더만 업로드하면 됩니다. 상위 폴더의 HWPX·XLSX 원본이나 `analysis` 폴더는 사이트 실행에 필요하지 않습니다. 공개되는 데이터는 `data.js`의 교육과정·과목별 합계 인원·개설반 정보입니다. 학생 개인 자료는 포함하지 않습니다.

공식 안내: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 계산 기준

- 2025·2026 입학생: 13학급. 2027 이후 입학생: 12학급.
- 2028·2029 입학생은 2027 입학생 교육과정을 적용합니다.
- 반당 주당시수는 HWPX의 운영 학점을 기준으로 둡니다. 실제 주간 편성은 화면에서 수정할 수 있습니다.
- 주당시수 = 반당 주당시수 × 개설 반 수.
- **학기별 교사 1인 평균 = (자체 과목 시수 + 배정받은 시수) ÷ 해당 학기 교사 수**. 소수 둘째 자리까지 표시합니다. 교사 수가 빈칸 또는 0명이면 ‘미산정’입니다. 미정 과목이나 반영이 보류된 배정이 있으면 별표를 표시합니다.
- 교사 수 초기값은 첨부 배당표 `배정` 시트 U열의 **2026학년도 교과교사 정원**입니다. 국어·수학·영어 각 10명 등 18개 교과, 총 68명을 2027~2029학년도 각 학기의 참고값으로 적용합니다. 미래의 확정 정원이 아니므로 실제 인원에 맞게 수정합니다. 진로 1명은 창체 담당이므로 이 교과 합계에서 제외합니다.
- 사회 공통·과학 공통 및 융합·교양은 시수를 담당 교과에 배정합니다. 교사 수는 담당하는 18개 교과에만 입력합니다. 이전 예상안에 입력된 공통·교양 교사 수는 파일에 보관하지만 인원 합계와 평균에서는 제외합니다. 창체는 배정 대상에서 제외합니다.
- 연평균 주당시수 = (1학기 주당시수 + 2학기 주당시수) ÷ 2. 두 학기 합을 연평균으로 표시하지 않습니다.
- 2027학년도 2·3학년은 선택인원 XLSX의 **최종 인원 W열·개설반 X열**을 사용합니다.
- 미래 선택과목은 같은 과목의 기존 자료를 참고합니다. 동일 학년, 동일 학기를 우선하고, `참고 반 수 × 해당 입학생 학급 수 ÷ 13`을 반올림합니다. 0반은 0, 양수는 최소 1반입니다. 인원도 같은 비율로 반올림합니다.
- 같은 과목의 자료가 없으면 **미정**입니다. 미정을 확정된 0으로 표시하지 않으며 합계에 **입력분·부분 합계**를 표시합니다.
- 2028학년도 미정: 영미 문학 읽기, 경제 수학, 인공지능 수학, 독서 토론과 글쓰기.
- 2029학년도 미정: 영미 문학 읽기, 세계 문화와 영어, 인공지능 수학, 독서 토론과 글쓰기.
- 예상 반 수는 선택군 수요를 맞춘 확정 시간표가 아닙니다. ‘선택군별 반 수 점검’의 학급 수 × 선택 과목 수 기준을 참고하여 조정합니다.
- 선택군의 ‘택1·택3·택4’는 원본 교육과정의 학생 1인당 선택 과목 수입니다. A·B 등의 문자는 입학 연도별 원자료 묶음 순서에 붙인 조회용 이름이며, 서로 다른 입학 연도에서 같은 문자가 같은 선택군을 뜻하지는 않습니다. 학교 지정 과목과 선택군이 지정되지 않은 추가 과목도 각각 조회할 수 있습니다.
- 예술·정보·한문의 학기교차는 12학급일 때 6/6, 13학급일 때 6/7반으로 교차 편성한 가정입니다.
- 미배정 시수는 원래 사회 공통·과학 공통 및 융합·교양 구분에 남습니다. 교과별 비교와 담당 교과별 배당표에서는 배정분을 담당 교과로 옮겨 집계하여 학교 전체 합계를 유지합니다.
- 2027 입학생 지구과학은 원본에 2학년 1·2학기 모두 있습니다. 그대로 반영했으며 학생별 중복 이수는 따로 검토해야 합니다.
- 배당표는 **검토용 집계**이며 첨부 엑셀의 공식 제출 양식을 그대로 재현한 파일은 아닙니다.

## 공통·융합·교양 시수 나누기

1. **공통·교양 시수 배정**에서 학년도와 학기를 고릅니다.
2. 과목의 **배정하기**를 누릅니다. 사회 공통은 역사·일반사회·지리·윤리, 과학 공통 및 융합은 물리학·화학·생명과학·지구과학 안에서 배정합니다. 교양은 전체 18개 교과 중 선택합니다.
3. 담당 교과별 **주당시수**를 입력합니다. 예를 들어 통합사회 4시간 × 12반 = 48시간 중 일반사회에 4반을 맡기면 16시간을 입력합니다. 여러 교과가 나누어 맡을 수 있으며 소수 둘째 자리까지 입력할 수 있습니다.
4. **평균이 낮은 교과로 배정안 제안**을 누르면 현재 부하와 교사 수를 참고하여 0.5시간 단위로 배정안을 제안합니다. 교사 수 미정·0명, 자체 과목 시수 미정 또는 보류된 배정이 있는 교과는 제외합니다. 제안은 즉시 저장되지 않으며 직접 고친 뒤 **배정 적용**을 누릅니다. 담당 가능 여부, 실제 분반과 시간표는 별도로 확인합니다.
5. 총시수보다 많이 배정하면 적용할 수 없습니다. 일부만 배정해도 되며 남은 시수는 **미배정**으로 표시됩니다. 평균, 3개년 교과별 비교, 담당 교과별 배당표 및 CSV에 반영됩니다.

개설 반 수나 반당 시수가 바뀌어도 배정한 숫자는 자동으로 바뀌지 않습니다. 과목 총시수가 줄어 배정 합계가 초과하면 그 과목의 기존 배정 전체를 **반영 보류**하고 재배정을 안내합니다. 시수가 미정이거나 미개설이면 배정을 보관하되 평균에 더하지 않습니다. 다시 개설하고 총시수가 충분하면 보관한 배정을 반영합니다.

**입력 비우기 → 배정 적용**으로 해당 과목의 배정을 해제합니다. **되돌리기**로 직전 배정 변경도 복원할 수 있습니다. 배정 내역 CSV는 과목별 입력값·실제 반영값·남은 시수·상태를 구분하며, 담당 교과별 배당표 CSV는 실제 반영 시수를 학년·학기별로 내보냅니다.

## 검산 기준값

수정 전 2027학년도 교과 합계는 1학기·2학기 각각 **1,102시간/주**입니다. 창체 3시간 × 38학급 = 114시간/주를 더하면 각각 **1,216시간/주**로 첨부 배당표 합계와 일치합니다.

2028학년도는 미정 4건을 제외한 1,049 / 1,040시간, 2029학년도는 미정 4건을 제외한 1,023 / 980시간입니다. 미래값은 참고 추정이며 확정 시수가 아닙니다.

## 구성

외부 라이브러리나 외부 글꼴을 사용하지 않습니다. 모든 자원 경로는 상대 경로이므로 GitHub Pages 하위 폴더에서도 실행됩니다. `data.js`는 원자료, `model.js`는 계산, `assignments.js`는 공통·교양 배정 화면, `app.js`는 나머지 화면과 저장 기능입니다.
